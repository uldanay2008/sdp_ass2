# Clean Code Principles

## 1. Meaningful Names

Classes and methods have clear names, for example `MissionControl`, `createSpacecraft()` and `createPropulsionSystem()`.

## 2. Single Responsibility

Each class has one main responsibility. For example, factories are responsible for creating products.

## 3. Small Methods

Methods such as `activate()`, `explore()` and `deploy()` perform simple tasks and are easy to understand.

## 4. Programming to Interfaces

The client works with interfaces instead of concrete classes. This makes the code more flexible.

## 5. No Magic Numbers or Strings

The project avoids unnecessary hard-coded numbers and strings. Meaningful names are used when constants are needed.

## Conclusion

These principles make the code clean, readable, maintainable, and easy to extend.
